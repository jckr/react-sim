# Basic blocks

At the core of the engine you provide two functions:

- `init(params)` to create the initial dataset
- `step({ data, params, tick })` to compute the next dataset

Wrap them in `defineSim` from `react-sim-engine/sim` to create a sim module.

## React adapter

- Import **`Simulation`** from **`react-sim-react/simulation`**, **`useSimulation`** from **`react-sim-react/hooks`**, and **`StandardControls`** from **`react-sim-react/controls`**.
- Pass your sim module as `<Simulation sim={mySim}>`. Engine options (`maxTime`, `delayMs`, `ticksPerFrame`) are top-level props.
- Inside the tree, call **`useSimulation<typeof mySim>()`** for typed state and actions (`play`, `pause`, `stop`, `seek`, `advance`, `setParams`, `resetWith`).
- **Composable controls:** import primitives from **`react-sim-react/control-primitives`** (`PlayPauseButton`, `StopButton`, `StepButton`, `ResetButton`, …).
- **Batteries included:** **`StandardControls`** bundles transport + optional param fields.
